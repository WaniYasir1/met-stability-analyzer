# MET Stability Analyzer

Shiny application for Multi-Environment Trial (MET) stability analysis.

## Features
- Critical Difference (CD)
- GxE ANOVA
- Environment ANOVA
- Eberhart-Russell Stability

## Run the App

install.packages(c('shiny','dplyr','ggplot2','DT'))

shiny::runApp()

## Data Format

ENV | GEN | REP | Trait columns
